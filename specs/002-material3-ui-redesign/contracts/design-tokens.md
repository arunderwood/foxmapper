# Contract: Design Tokens

**Consumers**: every stylesheet and every TS module that sets a style (map layers, wedge
rendering, blank fallback style, brand assets). **Producer**: `web/src/ui/tokens.css`,
generated by `web/scripts/generate-tokens.mjs` and committed.

## The contract

1. **Single source**: `tokens.css` is the only file that may define a colour, corner
   radius, easing, duration, opacity step, or type-scale value. Everything else consumes
   `var(--md-sys-*)` / `var(--fx-*)`. TS modules that need a colour (map layers, the blank
   fallback style, canvas/SVG rendering) read it from the computed style of `:root` or
   import a generated constants module — they do not restate hex values.
2. **Naming**: M3 system-token names for everything M3 defines (`--md-sys-color-*`,
   `--md-sys-shape-corner-*`, `--md-sys-motion-*`, `--md-sys-typescale-*`,
   `--md-sys-state-*`). FoxMapper-specific roles use the `--fx-` prefix (`--fx-color-warn`,
   `--fx-kind-bearing`, `--fx-touch`). No third naming scheme may appear.
3. **Deletion, not aliasing**: the legacy variables (`--bg`, `--surface`,
   `--surface-raised`, `--line`, `--text`, `--text-dim`, `--accent`, `--warn`,
   `--danger`, `--touch`, `--radius`) are removed. A grep for them in `web/src` after the
   redesign must return only `tokens.css`-adjacent history (SC-008). `--touch` is renamed
   `--fx-touch`, `--mono` may survive as `--fx-font-mono`.
4. **Contrast floors** (verified by `web/tests/unit/contrast.test.ts`, which parses this
   file's role pairs from `tokens.css`):
   - Glanceable tier ≥ **7.0:1**: `on-surface` and every status colour (`primary`,
     `--fx-color-warn`, `error`, `--fx-color-ok`) against `surface` and
     `surface-container`; filled-button label pairs (`on-primary`/`primary`,
     `on-primary-container`/`primary-container`).
   - Body tier ≥ **4.5:1**: `on-surface-variant` against all surfaces.
   - Non-text ≥ **3.0:1**: `outline` and the four `--fx-kind-*` hues against their
     containers.
5. **Field constants are floors**: `--fx-touch: 56px` may only appear in `min-height`/
   `min-width`; `--fx-input-font: 16px` is the minimum input font size. No token may be
   consumed in a way that reduces either.
6. **Dark only**: `color-scheme: dark` stays; no light-scheme tokens are emitted (spec
   assumption). The generation script hard-fails if asked for a light scheme.
7. **Regeneration**: `node web/scripts/generate-tokens.mjs` regenerates the reference tier
   from the seed and re-derives the system tier. Output is deterministic (same seed →
   byte-identical file). Manual edits go in a clearly marked hand-tuned block that the
   script preserves; the contrast test is the arbiter either way.
8. **Frozen palette**: the script and this token set MUST NOT touch `web/src/log/colour.ts`
   or the 9-swatch callsign palette documented in `docs/log-format.md`.

## Change discipline

A PR that changes a token value must show the contrast test passing; a PR that adds a
token must justify why an existing role doesn't cover it (constitution V's "new concepts
require justification", applied to design vocabulary).
